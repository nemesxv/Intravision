INTRAVISION — АВТОМАТ ПО ПРОДАЖЕ НАПИТКОВ

Веб-приложение моделирует работу автомата по продаже напитков.
Состоит из двух страниц: публичного интерфейса покупателя и административного
интерфейса с доступом по секретному ключу в параметре URL.

Развёрнутая версия
Пользовательский интерфейс: http://95.165.103.141:5081/
Административный интерфейс:
http://95.165.103.141:5081/admin?key=5sBdg210XtM-t3PEo-yiT1PSillVyHdvjvrvVhFhU8w
Ключ администратора: 5sBdg210XtM-t3PEo-yiT1PSillVyHdvjvrvVhFhU8w

Ключ опубликован только для удобства проверки тестового задания. В рабочем
окружении секретный ключ хранится в защищённой конфигурации и не публикуется.

Технологии
.NET 10, ASP.NET Core Web API, React 19, Vite 8,
Entity Framework Core 10, SQL Server Express LocalDB.
Работа с базой данных реализована по подходу Code First с миграциями.

Реализация
Покупатель вносит монеты 1, 2, 5 и 10 рублей, выбирает напиток нажатием
на изображение и получает сдачу. Законченные и недоступные по цене напитки
нельзя выбрать. Заблокированные монеты не принимаются, но используются
при выдаче сдачи.

Администратор добавляет, редактирует и удаляет напитки, управляет их ценой,
количеством и необязательными изображениями, изменяет запас монет и блокирует их приём.

React взаимодействует с HTTP API без перезагрузки страницы.
Бизнес-логика выделена в сервисы с зависимостями через интерфейсы.
Денежные значения хранятся как decimal. Покупка обновляет товар, монеты
и кошелёк одной транзакцией; RowVersion защищает от конфликтующих изменений.
Расчёт сдачи учитывает ограниченный запас монет. Если точную сдачу выдать
невозможно, баланс и остатки сохраняются. Предусмотрены серверная валидация,
защита изменяющих запросов от CSRF и автоматизированные проверки.

Необязательные требования — выполнены оба
1. Импорт напитков из JSON с проверкой данных и изображений.
2. Покупка нескольких напитков перед получением сдачи:
   остаток сохраняется на балансе до явного возврата пользователем.

Запуск и документация
Инструкции по запуску, архитектура, API и команды проверок описаны в README.md.
Готовая сборка React включена в проект и обслуживается .NET.
Для проверки в Development предусмотрен ключ intravision:
  /admin?key=intravision
Ключ задан исключительно для удобства проверяющего. В production он не должен
присутствовать или использоваться; необходимо настроить собственный секрет.
